# One-Page Website

A travel-themed one-page website built with HTML, CSS, and JavaScript.

Open `one_page_website.html` in a browser to view the page. Select any gallery photo to open the accessible lightbox; the gallery supports the keyboard arrow keys and Escape.

## Files

- `one_page_website.html` — page content and image thumbnails
- `one_page_website.css` — responsive page and lightbox styles
- `JS/one_page_website.js` — interactive image lightbox
